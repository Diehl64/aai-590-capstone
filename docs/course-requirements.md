# Course requirements and milestones

Source: the AAI-590 syllabus, Capstone Project Guidelines, report template, GitHub README guidance, and peer evaluation form supplied by Tony. Individual module prompts and the instructor's final rubric remain authoritative for additional detail.

## Team deliverables

| Requirement | Team of three |
| --- | --- |
| Team formation | Join the appropriate Canvas team in Week 1 |
| Project effort | Plan approximately 15 hours per member per week for seven weeks |
| Learning method | At least one neural network/deep learning model |
| Training | Train a model or fine-tune a pretrained model; inference alone is insufficient |
| Original work | Sufficient capstone complexity; do not simply reproduce a tutorial or prior course submission |
| Final report | One per team, maximum 20 pages including figures and references; appendices excluded |
| Code hosting | GitHub required; public or shared with the instructor |
| Code coverage | Cleaning, EDA, model/pipeline building, training, optimization, analysis and discussion |
| Code submission | Repository URL plus PDFs for notebook work and .py files for raw Python work |
| Presentation | One recorded team presentation, at least eight visualizations and at least two speaking minutes per member |
| Duration conflict | Guidelines say both less than 10 minutes and 8–12 minutes for teams of 3+; target 8 to under 10 minutes unless clarified |
| Peer evaluation | Each member submits confidential evaluations of teammates |

## Weekly milestones

| Module | Required milestone |
| --- | --- |
| 1 | Form team, select topic and dataset, complete introduction draft |
| 2 | Complete project management plan |
| 3 | Clean data, perform EDA, complete dataset summary draft |
| 4 | Select methods/tools, complete background/literature draft |
| 5 | Begin training/system work, complete methodology draft |
| 6 | Complete training/system work, begin results section |
| 7 | Complete report, code repository, presentation, and peer evaluations |

The guidelines recommend meeting the professor at least once, preferably during Weeks 3–5. Add actual Canvas dates to issues after checking the calendar.

## Report structure

Use the supplied template: title/authors, abstract, keywords, Introduction, Data Summary, Literature Review, Methodology, Results, Conclusion, and APA 7 references. Acknowledgments and appendices are optional. Write the abstract last. Remove template instructions and formatting examples before submission.

Write primarily in cohesive paragraphs for semi-technical stakeholders. Describe architecture and procedures without narrating code function calls. Keep performance findings in Results, cite datasets/libraries/architectures and borrowed ideas, and discuss every included figure or table in the text.

## Grade allocation

Discussions 90; module assignments 210; report 300; code 200; presentation 150; peer evaluation 50. Total 1,000 points; an A begins at 940.

Follow the instructor's AI-use policy and disclose permitted assistance accurately. Do not upload course materials or confidential peer evaluations as part of a public project release without appropriate permission.
